# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the label strings used in this repo's issue tracker. The project keeps the default vocabulary, which is also the one in [agentic development](../agentic-development.md#workflow).

| Role | Label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | The owner needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting for more information (also: a ticket without acceptance criteria) |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK `implementer` agent |
| `ready-for-human` | `ready-for-human` | Needs the owner in the session (HITL): design questions, accounts, secrets, manual steps |
| `wontfix` | `wontfix` | Will not be actioned |

Category roles reuse GitHub's default labels `bug` and `enhancement`.
